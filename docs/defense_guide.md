# Шпаргалка к защите (недели 1–6)

Документ помогает разобраться в коде и ответить на вопросы преподавателя.
Читай вместе с кодом: у каждого файла в `lib/` есть комментарии на русском.

## Как устроено приложение за 1 минуту

1. `main.dart` — инициализирует Hive, вызывает `configureDependencies()` (get_it)
   и запускает `HabitStudyTrackerApp`.
2. `app.dart` — создаёт BLoC-и (`HabitsBloc`, `QuoteCubit`, `FavoritesCubit`) и
   `SettingsNotifier`, строит `MaterialApp` со светлой/тёмной темой и локализацией.
3. `HomeShell` — нижняя навигация на 4 вкладки: Сегодня, Статистика, Материалы, Настройки.
4. Экраны **не знают**, откуда данные: они отправляют события в BLoC,
   BLoC обращается к **интерфейсу** репозитория, а реализация (Hive, сеть)
   подставляется через get_it.

## Маршрут одного нажатия (выучи наизусть)

«Пользователь отметил цель выполненной»:

```
HabitTile (кружок) → onToggle
  → context.read<HabitsBloc>().add(HabitToggled(id, today))      // presentation
  → HabitsBloc._onToggled: habit.toggleDay(today)                // domain (логика в сущности)
  → repository.saveHabit(...)                                    // интерфейс domain
  → HiveHabitRepository: box.put(id, json)                       // data
  → box.watch() → watchHabits() выдаёт новый список
  → emit.forEach → новое HabitsState
  → BlocBuilder перерисовывает «Сегодня», «Статистику», «Детали»
```

## Частые вопросы

**Что такое null safety?** Переменная не может быть `null`, если её тип не
помечен `?`. Компилятор не даст вызвать метод у `String?` без проверки.
Операторы: `?.` (вызвать, если не null), `??` (значение по умолчанию),
`!` (уверен, что не null), `late` (инициализирую позже). Пример — `dart_tasks/task1_null_safety.dart`.

**StatelessWidget vs StatefulWidget?** Stateless только отображает переданные
данные. Stateful хранит изменяемое состояние в объекте `State` и
перерисовывается через `setState`. У нас Stateful: `HomeShell` (вкладка),
`HabitEditScreen` (форма), `_MaterialsView` (контроллеры).

**Почему форма в `SingleChildScrollView`, а не `ListView`?** `ListView`
удаляет невидимые поля из дерева, и `Form.validate()` их не проверит.

**Чем отличаются setState / InheritedWidget / Provider?** См.
`docs/week3_state_management.md` — там таблица и код каждого шага (коммиты недели 3).

**Почему BLoC, а не Riverpod?** Явные события и состояния, удобная работа с
потоками (`emit.forEach`), готовые трансформеры (debounce, droppable),
простое тестирование через `bloc_test`. Provider оставлен для простых
настроек, где BLoC избыточен.

**Что такое BLoC и Cubit?** BLoC получает **события** и выдаёт **состояния**.
Cubit — упрощённый BLoC без событий: UI вызывает методы (`QuoteCubit.load()`).

**Что такое Repository?** Интерфейс в слое domain (`HabitRepository`),
который скрывает, где лежат данные. На неделе 4 была реализация в памяти,
на неделе 6 — Hive, на неделе 8 будет Firestore. BLoC не меняется.

**Что такое DI и get_it?** Объекты не создают свои зависимости сами, а
получают их через конструктор. get_it — «реестр», где мы один раз
регистрируем, как создать объект (`lib/core/di/injection.dart`).
`registerLazySingleton` — один на приложение, `registerFactory` — новый каждый раз.

**Зачем Equatable?** Сравнивает объекты по полям. BLoC не выдаёт состояние,
равное предыдущему, — лишних перерисовок нет.

**Как работает поиск с debounce?** `MaterialsBloc` применяет
`debounceRestartable(400 мс)`: запрос уходит, только когда пользователь
перестал печатать на 400 мс, а устаревший запрос отменяется (`restartable`).

**Как сделана пагинация?** `ScrollController` следит за прокруткой; за 300 px
до конца отправляется `MaterialsNextPageRequested`. Трансформер `droppable`
игнорирует повторные события, пока страница грузится.

**Как обрабатываются ошибки сети?** `DioException` → `mapDioException` →
`NetworkFailure` / `TimeoutFailure` / `ServerFailure` / `ParsingFailure` →
`failureMessage()` превращает в текст на нужном языке.

**Что такое DTO и зачем json_serializable?** DTO (`BookDto`) повторяет JSON
от сервера. Код `fromJson`/`toJson` генерируется (`book_dto.g.dart`), чтобы
не писать его руками и не ошибаться. DTO преобразуется в сущность `Book`.

**SharedPreferences vs Hive?** SharedPreferences — для пары простых значений
(тема, язык). Hive — быстрая NoSQL-база «ключ → значение» для списков и
объектов (цели, кэш, избранное).

**Что значит offline-first?** Приложение работает с локальными данными, а сеть
используется для обновления. Цели всегда в Hive; поиск при отсутствии сети
показывает кэш с плашкой; цитата дня берётся из кэша.

**Как считается серия (streak)?** `Habit.currentStreak()`: идём назад от
сегодняшнего дня; незапланированные дни пропускаем; невыполненный
**сегодняшний** день серию не обрывает (день ещё не закончился).

**Почему `DateTime(y, m, d - 1)`, а не `subtract(Duration(days: 1))`?** При
переходе на летнее время сутки длятся 23 или 25 часов, и `subtract` может
дать не тот день.
